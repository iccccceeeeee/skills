# Image 2.6

指定 Flare 或未指定变体时，按 [$image26-flare-icodeeasy](../image26-flare-icodeeasy/SKILL.md) 执行。
用户指定 Sunburst（也识别 `sunbrust`）时，按 [$image26-sunburst-icodeeasy](../image26-sunburst-icodeeasy/SKILL.md) 执行。

加载对应 skill，按其固定的模型 ID 调用。参数和任务恢复见 [API 参考](references/api.md)。
