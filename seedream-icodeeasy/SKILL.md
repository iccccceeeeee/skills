# Seedream via iCodeEasy

用户只说 Seedream 时使用 [Seedream 5.5](../seedream-5-5-icodeeasy/SKILL.md)，默认 2K、1:1。用户指定型号时直接按对应 skill 执行。明确调用本入口并指定型号时也按此规则执行。

| 型号 | 直接调用 |
| --- | --- |
| Seedream 5.5 | [`$seedream-5-5-icodeeasy`](../seedream-5-5-icodeeasy/SKILL.md) |
| Seedream 5 Flash | [`$seedream-5-0-flash-icodeeasy`](../seedream-5-0-flash-icodeeasy/SKILL.md) |
| Seedream 5 Pro | [`$seedream-5-0-pro-icodeeasy`](../seedream-5-0-pro-icodeeasy/SKILL.md) |
| Seedream 5.0 Lite | [`$seedream-5-0-lite-icodeeasy`](../seedream-5-0-lite-icodeeasy/SKILL.md) |
| Seedream 4.5 | [`$seedream-4-5-icodeeasy`](../seedream-4-5-icodeeasy/SKILL.md) |
| Seedream 4.0 | [`$seedream-4-0-icodeeasy`](../seedream-4-0-icodeeasy/SKILL.md) |
